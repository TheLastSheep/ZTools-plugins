# Changelog

## 2.0.0 - 2026-10-18

### Added

- 首次发布到 ZTools 插件市场。
- 按分类管理搜索引擎，支持新增、重命名、删除分类。
- 引擎支持新增、编辑、删除、上移、下移，搜索地址支持 `{q}` 与 `%s` 两种占位符。
- 三种搜索方式：单个引擎搜索、搜索本组、批量搜索已勾选引擎。
- 支持 ZTools 关键字触发（`so` / `搜索` / `多搜`）与全局文本触发。
- 支持 JSON 配置导入、导出、恢复默认，兼容旧版脚本导出的配置格式。
- 内置 5 个分类、23 个常用搜索引擎作为默认配置。
- 支持浅色 / 深色主题自动适配。
