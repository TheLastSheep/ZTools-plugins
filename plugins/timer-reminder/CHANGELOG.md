# Changelog

## 1.3.0 - 2026-10-12

### Added

- ICS 日历导入 / 导出（iCalendar RFC 5545）：待提醒页「导入日历 ICS」、已完成页「导出日历 ICS」，可与系统日历 / Outlook / Google Calendar 互通，也用于跨设备迁移
  - 导出：每条提醒一个 `VEVENT`，重复规则映射 `RRULE`（间隔 / 每小时 / 每天 / 每周 / 工作日 / 每月，支持 `COUNT` 与 `UNTIL`），生效时段以 `X-ACTIVE-WINDOW` 保留，附 `VALARM` 到点提醒，已停用 / 已完成导出为 `STATUS:CANCELLED`
  - 导入：解析 `VEVENT` 并还原重复规则，兼容 UTC / 本地 / 纯日期三种时间形式；`YEARLY` 等不支持的频率按无效跳过，已过期的单次事件导入为已完成
- 工作日提醒接入中国法定节假日与调休（`lib/holidays.js`，覆盖 2025–2026 年）：`workday` 重复规则按「调休上班日 > 放假日 > 普通周一~周五」判断，法定节假日不误触发、调休上班的周末正常触发；数据未覆盖的年份自动退化为普通周末判断，设置页「调度器」显示节假日数据覆盖年份

## 1.2.1 - 2026-10-12

### Fixed

- 修复「新建提醒」切换到重复模式时日期/时间字段仍显示（`.form-grid` 的 `display` 覆盖了 `hidden` 属性）；弹窗备注为空时不再占位
- 修复 toast 定时器会把正在显示的解析预览隐藏；AI 解析增加 350ms 防抖，避免每次按键都调用大模型
- 修复「补发错过的提醒」设置（`notifyOnMissed`）从未生效的问题
- 修复强提醒弹窗堆积：同一提醒再次触发时先关闭旧弹窗（兼容 `win.close()` / `removeBrowserWindow`），并限制同时存在的弹窗数
- 修复「这周五/本周五」在周五当天被解析为下周五；当天时刻已过时自动顺延到下周五
- 修复设置浅合并导致旧版本数据缺少新字段（如 `channels.webhook`）的升级兼容问题，改为深合并
- 修复多窗口（分离窗口等）列表不实时同步：按数据指纹检测变化后自动重建
- 修复弹窗「稍后 10 分钟」写死时长，现跟随设置中的 `snoozeMinutes`
- 修复开发预览服务器路径穿越检查可被同前缀目录绕过（如 `ztools-evil`）

### Added

- 网络请求支持环境变量代理（`HTTPS_PROXY` / `HTTP_PROXY`，遵循 `NO_PROXY`；HTTPS 走 CONNECT 隧道，支持代理认证），大模型 / 短信宝 / Webhook 在需要代理的网络下可用
- ZTools 搜索框快捷指令支持「每30分钟 喝水」「每半小时 站立」等以「每+数字」开头的重复提醒
- 设置页 SMTP 加密方式补充网络环境提示（587 明文可能被拦截时改用 SSL/TLS）

## 1.2.0 - 2026-10-09

### Changed

- 导入导出改为 Excel（xlsx）格式：零依赖内置 xlsx 读写引擎，兼容真实 Excel 的 sharedStrings 与日期序列号
- 「导入 Excel」按钮移至待提醒页底部，「导出 Excel」按钮移至已完成页底部（导出已完成列表）
- 移除设置页「数据管理」区块

## 1.1.0 - 2026-10-08

### Added

- 待提醒 / 已完成列表支持导出为 JSON（全部 / 待提醒 / 已完成）与导入合并
- 额外提醒通道：邮件（内置 SMTP 客户端，SSL/STARTTLS）、短信（短信宝）、自定义 Webhook
- 密钥（SMTP 密码 / 短信密钥 / 大模型 API Key）改存 ZTools 加密存储 dbCryptoStorage
- 接入大语言模型（OpenAI 兼容接口）：规则解析失败时自动 AI 解析自然语言

## 1.0.0 - 2026-10-08

### Added

- 首个公开版本：一次性 / 周期性定时提醒（间隔、每小时、每天、每周、工作日、每月）
- 自然语言快速创建：如「10分钟后 喝水」「明天9点 开会」「每周一三五 9:00 例会」
- 到点系统通知 + 响铃，可选置顶弹窗强提醒；支持稍后提醒、完成、停用、编辑、删除
- 插件重启自动续期，停机期间错过的提醒启动时补发
- 多窗口心跳锁，避免主窗口与分离窗口重复触发
- 跟随 ZTools 浅色 / 深色主题
